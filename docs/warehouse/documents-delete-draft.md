# Удаление черновика складского документа

## Задача

В списке документов `/crm/warehouse/documents/:docType` добавлена кнопка «Удалить черновик» (иконка корзины).
Бэкенд должен разрешить и безопасно выполнять удаление документа в статусе `DRAFT`.

## Контракт API

`DELETE /warehouse/documents/{id}/`

| Случай                                                                                                            | Ответ                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Документ в статусе `DRAFT`, права есть                                                                            | `204 No Content`, документ и его позиции удалены                                                                                    |
| Статус не `DRAFT` (`POSTED`, `CASH_PENDING`, `REJECTED`)                                                          | `400` `{"detail": "Удалить можно только черновик. Сначала отмените проведение."}`                                                   |
| Документ — заявка агента (`doc_type=SALE`, `is_sale_request=true`, связан с корзиной агента `cart.sale_document`) | `400` `{"detail": "Заявку агента нельзя удалить как черновик."}` (либо разрешить с корректной развязкой корзины — решение за бэком) |
| Нет прав                                                                                                          | `403` `{"detail": "..."}`                                                                                                           |
| Не найден / чужая компания / филиал                                                                               | `404`                                                                                                                               |

Фронт показывает пользователю `detail` из ответа при любой ошибке.

## Правила

- Удаление только при `status = DRAFT`. Движений по складу и кассе у черновика нет, откатывать нечего.
- Удалить вместе с позициями (`items`) и связанными черновыми сущностями.
- Если у черновика есть связанные деньги/платежи/долг контрагента (не должно быть) — вернуть `400`.
- Права: владелец/админ — любые черновики компании; сотрудник/агент — только свои (`created_by`) — подтвердить с продуктом.
- Желательно: запись в журнал действий (кто и когда удалил документ с номером).
- Мягкое удаление допустимо, если нужно сохранить номер в нумерации; тогда удалённые не должны попадать в `GET /warehouse/documents/` и в `count`.

## Чек-лист приёмки

- [ ] `DELETE` на `DRAFT` возвращает `204`, документ исчезает из списка и `count` уменьшается
- [ ] `DELETE` на `POSTED` / `CASH_PENDING` / `REJECTED` возвращает `400` с понятным `detail`
- [ ] Заявку агента (`SALE_REQUEST`) нельзя удалить (или корректно разрывается связь с корзиной агента)
- [ ] Сотрудник без прав получает `403`
- [ ] Документ из другой компании/филиала — `404`
- [ ] Остатки на складах и баланс контрагента не меняются
- [ ] Повторный `DELETE` того же id — `404`
