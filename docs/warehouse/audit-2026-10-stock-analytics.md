## 5. План работ

### Этап 0 — данные и срочные исправления (P0)

1. `reconcile_warehouse_stock --report` → решения D1 → применение документами `INVENTORY`.
2. Начальные остатки для 4 046 товаров без `StockBalance`.
3. A1 + A2: исправить маппинг денег и авто-категорию; `fix_receipt_money_documents` (D2).
4. Сбросить кэш аналитики.

### Этап 1 — остатки (S1–S8)

1. Миграция `StockMove` (`document` nullable, `source_kind`, `source_id`).
2. Сервис `apply_stock_delta` / `get_on_hand`, удаление `max()`.
3. Агентские выдачи и возвраты через сервис; удаление строк из S5.
4. `quantity` read-only в API, эндпоинт `stock-adjustment`, начальный остаток при создании.
5. Фронт: read-only количество + «Корректировка остатка».
6. Задача `check_stock_consistency`.

### Этап 2 — расчёты аналитики (A3–A16)

1. A5 (остатки по `StockBalance`), A6, A7, A3.
2. `DocumentItem.net_amount` + backfill → A8, A9.
3. A10, A11, A13, A14.
4. Фронт: новые поля, A12, A15, A16.

### Этап 3 — полнота (C1–C5)

1. `DocumentItem.cost_price` + backfill.
2. Блоки «Закупки», «Движение товара», «Агенты», «Зарплата», «Прибыль».
3. Выплата ЗП через кассу (D6).
4. Фронт: новые KPI и аккордеоны.
