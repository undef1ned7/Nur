# Записи — зарплата мастера (% и фикс за запись)

**Сферы:** Барбершоп, Услуги, Стоматология.  
**Фронт:** два параллельных модуля (см. ниже).

---

## 1. Задача

Владельцу нужна зарплата мастера **не только фиксом за каждую запись**, но и **процентом от суммы записи** (и при необходимости комбинация: % + фикс + бонус за товары).

---

## 2. Что уже есть на фронте

### A. Выплаты в карточке сотрудников (работает с API)

**Путь:** Сотрудники → вкладка **«Выплаты»**  
**Файлы:** `MastersPayouts/MastersPayouts.jsx`, `RecordaRates/RecordaRates.jsx`  
**API:** `GET/POST/PUT /barbershop/payouts/`

| Режим       | Поле             | Формула                                      |
| ----------- | ---------------- | -------------------------------------------- |
| **percent** | `% от выручки`   | `round(выручка_завершённых × percent / 100)` |
| **record**  | `сом за запись`  | `кол-во_завершённых × фикс`                  |
| **fixed**   | `оклад за месяц` | фиксированная сумма                          |

**Итого за период:**

```
ЗП = завершённые × perRecord + round(выручка × percent / 100) + fixed + бонус_за_товары
```

- В расчёт попадают только записи со статусом **`completed`**.
- Выручка — поле `appointment.price` (итог записи с учётом скидки).
- Можно задать **и процент, и фикс за запись одновременно** для одного мастера.

### B. Новый модуль «Зарплата» (ждёт бэкенд)

**Путь:** меню **Зарплата** → `/crm/{barber\|services\|dentistry}/salary`  
**Файлы:** `Salary/Salary.jsx`, `api/servicesSalary.js`  
**Спека:** [salary.md](./salary.md)

- **% от каждой услуги** в записи (ставка на услугу, не на мастера).
- Начисление при **`completed`**, построчно по услугам.
- Требует реализации API на бэке.

---

## 3. Рекомендация

| Сценарий                               | Что использовать                                                    |
| -------------------------------------- | ------------------------------------------------------------------- |
| «40% от всех записей мастера»          | **Выплаты** → режим **percent**                                     |
| «200 сом за каждую завершённую запись» | **Выплаты** → режим **record**                                      |
| «200 сом + 30% от выручки»             | **Выплаты** → оба поля заполнить                                    |
| «Стрижка 40%, окрашивание 25%»         | **Зарплата** (после бэка) или договориться через общий % в Выплатах |

**Сейчас для production:** вкладка **Выплаты** у сотрудника — единственный рабочий вариант с % от записи.
