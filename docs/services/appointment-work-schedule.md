# Записи — график работы календаря

**Сферы:** Барбершоп, Услуги, Стоматология — `barbershop`.  
**Фронт:** `Recorda.jsx`, `recordaWorkHours.js`, `RecordaWorkSchedulePanel.jsx`.  
**Настройки:** Настройки → Онлайн → «График работы для записей»; на странице Записи — кнопка с часами.

---

## 1. Задача

Шкала времени слева в календаре (`09:00` … `21:00`) должна строиться из **графика работы компании**, а не быть захардкоженной.

---

## 2. Поля компании (бэкенд)

`PATCH /api/users/settings/company/`:

| Поле | Тип | Пример |
|---|---|---|
| `appointment_work_start` | `HH:MM` | `"08:00"` |
| `appointment_work_end` | `HH:MM` | `"20:00"` или `"00:00"` (полночь = конец дня) |

`GET /api/users/company/` — те же поля в ответе.

До реализации на бэке фронт сохраняет график в `localStorage` (`barber_appointment_work_schedule`).

---

## 3. Приоритет на фронте

1. **Все мастера** — график из настроек компании / localStorage.
2. **Выбран один мастер** — его `work_start` / `work_end` из  
   `GET /barbershop/public/{slug}/masters/{id}/schedule/?date=…`, если API ответил.
3. Если есть записи **вне** диапазона — шкала расширяется, чтобы их показать.

**`00:00` в `appointment_work_end`** — конец смены в полночь (шкала до 24:00),
а не «ноль минут от начала суток».

**`02:00` при начале, например, `09:00`** — конец **следующего утра** (ночная смена:
шкала идёт 09:00 … 24:00, 00:00, 00:30 … 02:00). Это не «2 часа дня».

---

## 4. Чек-лист

- [ ] `appointment_work_start` / `appointment_work_end` в модели Company.
- [ ] PATCH settings принимает и возвращает поля.
- [ ] Календарь меняет диапазон после сохранения без перезагрузки страницы.
