# 4. Счётчики и суммы на доске воронки

**Фронт:** `Funnel/Funnel.jsx` — переключатель «Мои / Все / Пул» со счётчиками,
заголовок стадии с количеством и суммой.

## 4.1. Текущее состояние

Счётчики «Мои / Все / Пул» уже считаются **на фронте** по загруженным доскам, и
для типовых объёмов этого достаточно — отдельный эндпоинт не требуется. Суммы по
стадиям (`funnel__colSum`) фронт тоже считает сам.

Серверная часть нужна в двух случаях:

1. досок много и лидов больше ~2000 — считать на клиенте становится дорого;
2. вводится серверная пагинация карточек внутри стадии (сейчас доска отдаётся
   целиком).

Ниже — контракт на этот случай. **Реализовывать не срочно** (приоритет 5), но
если делаете доску постранично — сделать обязательно, иначе счётчики начнут
врать (покажут длину страницы, а не всю стадию).

## 4.2. Что должна отдавать доска

```
GET /consalting/funnels/{id}/board/?owner_scope=&owner=&search=&grade=&at_risk=&needs_reply=
```

| Параметр | Значения |
|---|---|
| `owner_scope` | `mine` \| `all` \| `pool` (по умолчанию `mine` для сотрудника) |
| `owner` | uuid — фильтр по ответственному (только для менеджера) |
| `search` | icontains по `title`, `full_name`, `phone`, `email` |
| `grade` | `A` \| `B` \| `C` |
| `at_risk`, `needs_reply` | `true` |

```jsonc
{
  "funnel": { "id": "…", "name": "Продажа", "is_final": true },
  "scope_counts": { "mine": 14, "all": 63, "pool": 7 },
  "totals": { "count": 63, "amount": 2450000 },
  "columns": [
    {
      "stage": { "id": "…", "name": "Переговоры", "color": "#3498db", "order": 2 },
      "count": 8,
      "amount": 420000,
      "overdue_count": 2,
      "leads": [ /* карточки текущей страницы */ ]
    }
  ],
  "unassigned": []
}
```

**Главное правило:** `count`, `amount`, `scope_counts` считаются по **всей**
выборке с учётом фильтров, а не по отданной странице.

```python
qs = base_leads_qs(funnel, user, filters)          # общий фильтр без scope
scope_counts = qs.aggregate(
    all=Count("id"),
    mine=Count("id", filter=Q(owner=user)),
    pool=Count("id", filter=Q(owner__isnull=True)),
)
per_stage = (qs.filter(scope_q)
               .values("stage")
               .annotate(count=Count("id"),
                         amount=Sum("estimated_value"),
                         overdue_count=Count("id", filter=Q(is_sla_overdue=True))))
```

`amount` — сумма `estimated_value` (ожидаемая сумма сделки). Если поле пустое —
считайте 0, не исключайте карточку из `count`.

## 4.3. Права

- Сотрудник: `owner_scope` может быть только `mine` или `pool`; `all` для него
  трактуется как `mine` (фронт это уже ограничивает, но сервер обязан
  продублировать).
- `scope_counts.all` сотруднику отдавать не нужно — верните `null` или равным
  `mine`.

## 4.4. Чек-лист приёмки

- [ ] Счётчики учитывают активные фильтры (поиск, ответственный, грейд).
- [ ] Цифры не меняются при переключении страницы внутри стадии.
- [ ] Сотрудник не видит `all`.
- [ ] `amount` по стадии совпадает с суммой карточек этой стадии.
